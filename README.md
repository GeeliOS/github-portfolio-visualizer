# GitHub Portfolio Visualizer

Портфолио GitHub пользователей с графиками и статистикой.

Ссылка на прототип: https://geelios.github.io/github-portfolio-visualizer/


## ✨ Особенности

- 📊 Просмотр профиля GitHub пользователя
- 📈 Графики распределения языков программирования
- 🔍 Поиск и фильтрация репозиториев
- 📱 Адаптивный дизайн
- 🌙 Темная тема

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ваш-username/github-portfolio-visualizer.git
cd github-portfolio-visualizer 
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите приложение:

```bash
npm start
```

## Использование

1. Введите имя пользователя GitHub в поисковую строку
2. Нажмите "Поиск" или Enter
3. Изучайте профиль, репозитории и статистику языков
4. Используйте фильтры и сортировку для навигации по репозиториям

## ⚠️ Ограничения

1. Лимиты GitHub API - 60 запросов в час без токена
2. Пагинация репозиториев - загружаются все репозитории пользователя

## 🐛 Отладка и решение проблем
### Белый экран при загрузке

1. Проверьте консоль разработчика (F12)
2. Убедитесь, что GitHub API доступен
3. Проверьте интернет-соединение

### Ошибка 403 (Превышен лимит)

1. Подождите 1 час
2. Попробуйте другого пользователя

### Не загружаются репозитории

1. Проверьте имя пользователя
2. Убедитесь, что пользователь имеет публичные репозитории
3. Проверьте сетевое соединение
